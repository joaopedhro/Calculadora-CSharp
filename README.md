# 🧮 Calculadora em C#

Projeto de uma calculadora desenvolvida em C#, utilizando o .NET, com o objetivo de praticar lógica de programação e os principais conceitos da linguagem.

## 🚀 Funcionalidades

- Soma, subtração, multiplicação e divisão.

- Menu interativo para escolher a operação.

- Validação de entradas utilizando TryParse.

- Proteção contra divisão por zero.

- Possibilidade de realizar várias operações sem reiniciar o programa.

## 🛠️ Tecnologias utilizadas

- C#

- .NET

- Visual Studio Code

## ▶️ Como executar

1. Tenha o .NET SDK instalado no computador.

2. Baixe ou clone este repositório.

3. Abra a pasta do projeto no terminal.

4. Execute o comando:

```bash
dotnet run
```
## 📚 Conceitos praticados

- Variáveis e tipos de dados.

- Estruturas condicionais (if/else e switch).

- Laços de repetição (while e do while).

- Métodos e retorno de valores.

- Validação de entradas com TryParse.

## 🎯 Objetivo

Este projeto foi desenvolvido para colocar em prática meus conhecimentos iniciais em C# e aprimorar minhas habilidades em desenvolvimento de software.
